    Truck driving bans¶

    Driving bans, exemptions and fines live in small .v3def files next to the files the game already loads: per country, per city and per cargo. Map and cargo mods can bring their own countries, cities and cargo this way. The examples in the def/ folder of this package show the format.

    1. Where the files go¶

    Country: /def/country/<country>.v3def   (<country> = country token, e.g. germany)
City:    /def/city/<city>.v3def         (<city> = city token, e.g. warszawa)
Cargo:   /def/cargo/<cargo>.v3def       (<cargo> = cargo token)

    If a country .v3def already holds entries (e.g. driver_wage), simply add the blocks below them. A missing file means no ban there - that is not an error. A line with a wrong format is logged as an error (file, line, value read) and is not used.

    2. Ban blocks¶

    Three kinds, each may appear more than once:

    driving_banapplies to all trucks
    driving_ban_adrdangerous goods only (cargo with an ADR class)
    driving_ban_oversizespecial transports only (heavy haulage jobs)

    Same layout as the companies' opening hours: one day per line, one or more time windows (hh.mm, hh.mm). A missing day has no ban. A ban across midnight is split over both days (saturday until 24.00, sunday from 00.00). Days: monday tuesday wednesday thursday friday saturday sunday

    Extra lines in the block (all optional):

    transit: trueapplies to through traffic only. Loading or unloading in the country / city (sender or target of the job) is free, so is driving out after unloading and to your own garage there.
    inbound: trueapplies only if the city is the job's target
    to: <country>applies only if the job's target country matches
    rural: trueapplies only outside cities
    tractor_solo: truea tractor without trailer is free
    min_cargo: 1500applies only from this cargo mass in kg
    share: 50an exemption only counts if the exempt cargo makes up at least this percentage of the load (mixed loads)
    combined: 150combined transport: a container chassis with a company that has a reach stacker (container_load: true) as sender or target is free up to this distance (km straight line)
    Exempt cargo categories as their own block, one entry per line:
  exempt :
  {
  milk
  meat
  }

    Fine as its own block inside the ban block:
  fine :
  {
  driver: 250 750       driver's share in EUR; several values = 1st, 2nd offence
  holder: 3750          holder's share in EUR (own truck), tiered the same way
  by_time: true         optional: values follow the time driven during the ban
                        (up to 1 h, up to 2 h, above) instead of the offence
  }
One value applies to every offence. If a city's ban block has no fine block,
the country's fine block of the same kind (driving_ban, _adr, _oversize)
applies. In a driver job you only pay the driver's share, with your own truck
both shares.

    City blocks replace the country blocks of the same kind for that city.

    3. Cargo categories (cargo .v3def)¶

    One line per category:
  ban_class[]: milk
  ban_class[]: perishable

    Categories:
  perishable     perishable food in general
  milk           milk and dairy products
  meat           meat and meat products
  fish           fish and fish products
  fruit_veg      fruit and vegetables
  bakery         fresh bakery products
  livestock      live animals
  flowers        cut flowers and plants
  post           mail and press
  medical        medicine and hospital supplies
  fuel           fuel for filling stations
  gas_supply     heating and medical gas
  construction   building site goods (steel, concrete, bitumen)
  event          event equipment
  removal        household removals
  animal_byprod  animal by-products
Milk, meat, fish, fruit/vegetables and bakery products also get perishable,
because some countries only name "perishable food".
Empty runs to a reserved / booked exempt cargo and after unloading an exempt
cargo are free.

    Example files¶

    All examples for download: resources_driving_ban.zip

    def/cargo/your_cargo.v3def 
    # Beispiel / example: frische Milch / fresh milk
# --- Eintraege / entries ---
ban_class[]: milk
ban_class[]: perishable
    def/city/your_city.v3def 
    # Beispiel / example: Stossverkehr werktags + Durchfahrtsverbot rund um die Uhr
# rush hours on weekdays + no through traffic around the clock
# --- Eintraege / entries ---
driving_ban :
{
monday: (07.00, 10.00) (16.00, 20.00)

wednesday: (07.00, 10.00) (16.00, 20.00)
thursday: (07.00, 10.00) (16.00, 20.00)
friday: (07.00, 10.00) (16.00, 20.00)
exempt :
{
construction
fuel
}

{
driver: 47 118
holder: 471
}
}

{
monday: (00.00, 24.00)
