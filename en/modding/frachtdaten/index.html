    Cargo data¶

    Small optional files set a surcharge per cargo and how the cargo is handled in partial loads. They sit next to the cargo files of the game.

    1. File¶

    Same folder and same name as the cargo, only with .v3def:

    /def/cargo/<cargo>.v3defe.g. /def/cargo/fuel_oil.v3def

    All lines are optional. Without a file the cargo behaves as in the game.

    2. Pay¶

    Freight jobs (own truck + job trailer) are paid like real traction:

    • up to 150 km 1.90 EUR/km, 150-400 km sliding, from 400 km 1.53 EUR/km
    • at least 80 EUR/h x (driving time + 1 h)
    • cargo market (own trailer) +20 %
    • urgency as delivery_window_coef in economy_data.sii

    3. Surcharge¶

    surcharge: 25percent on the freight price
    • no file or no line: no surcharge
    • empty runs get no surcharge
    • included: all ADR cargoes of the game (class 1: 30 %, classes 2 and 3: 25 %, classes 4, 6 and 8: 15 %)

    4. Partial loads (cargo market, own trailer)¶

    load_unit: palletsingle | pallet | whole
    • whole = full load only, never a partial load
    • single, pallet = partial loads allowed (piece goods or pallets)
    • no line = partial loads allowed if the companies allow them (units_out / units_in, see README_company_data)

    Pay of a partial load: pallet rate (European average) by distance.

    • pallets = share of the trailer x 34
    • up to 5 pallets: 100 / 150 / 215 / 265 EUR at 100 / 350 / 650 / 1200 km
    • from 15 pallets: 70 / 105 / 150 / 190 EUR at 100 / 350 / 650 / 1200 km
    • sliding in between, rising further beyond 1200 km
    • at most the flat rate of the full load
    • urgency and surcharge apply as for the full load

    Waiting time for loading and unloading: in proportion to the amount, at least 10 minutes.

    5. Compatibility (adding cargo, tour planning)¶

    temp: 2;8temperature range from;to in degrees C
    food: truefood

    Only what fits together goes into one trailer:

    • temperature ranges must overlap (no temp line = fits everything)
    • food/feed never together with toxic cargo (ADR class 6, CV28) (ADR class from the game's cargo .sui, adr_class)
    • explosives (ADR class 1) never with other dangerous goods, allowed with normal cargo (ADR 7.5.2.1)
    • ADR classes 2 to 8 freely with each other

    6. Cargo model, lashing and loading¶

    lashing_method: directdirect | top_over
    lash_through: truetrue | false
    ramp: truetrue | false
    volume: 15.6volume per unit in m3
    unit_volume_factor: 0.1667factor per cargo model
    • lashing_method: lashing method of the cargo (direct = direct lashing at the cargo, top_over = tie-down over the cargo). Replaces the method of the cargo_model_match files of the cargo.
    • lash_through: true = the strap runs through the cargo (when securing by hand), e.g. for pipes or coils.
    • ramp: true = the cargo goes onto the trailer over the ramp (self-driving or rollable). In mixed loads only on low-bed trailers, never with a gooseneck.
    • volume: replaces the volume per unit of the game's cargo definition.
    • unit_volume_factor: replaces the factor of the cargo_model_match. Below 1 means: one cargo model is 1 / factor units (0.1667 = 6 units). Partial loads then come only in whole cargo models.

    7. Format¶

    key: value
    • one entry per line, spaces around the colon are allowed
    • lines starting with # or // are comments, a # after the value too
    • numbers with decimal point, no units on the line
    • a line with a wrong value is reported in game.log and ignored

    Example files¶

    All examples for download: resources_cargo_data.zip

    def/cargo/your_cargo.v3def 
    # Fleet & Road Realism - Frachtdaten / cargo data
# Datei / file: /def/cargo/your_cargo.v3def  (neben / next to /def/cargo/your_cargo.sui)
# Ueber jedem Eintrag steht die Beschreibung (# ...), der Eintrag selbst steht ohne #.
# Above each entry is its description (# ...), the entry itself has no #.

# Zuschlag auf den Frachtpreis in Prozent
# surcharge on the freight price in percent
surcharge: 10

# Teilladung: single | pallet | whole  (whole = nur Komplettladung)
# partial load: single | pallet | whole  (whole = full load only)
load_unit: pallet

# Temperaturbereich von;bis in Grad C  (ohne Zeile = jede Temperatur)
# temperature range from;to in degrees C  (no line = any temperature)
temp: 2;8

# Lebensmittel: true | false  (nie zusammen mit Gefahrgut)
# food: true | false  (nie mit giftiger Fracht ADR 6 / never together with toxic cargo ADR 6)
food: true
    def/cargo/your_machine.v3def 
    # Fleet & Road Realism - Beispiel: Maschine, faehrt ueber die Rampe auf
# Fleet & Road Realism - example: machine, drives on over the ramp
# Datei / file: /def/cargo/your_machine.v3def  (neben / next to /def/cargo/your_machine.sui)
# Ueber jedem Eintrag steht die Beschreibung (# ...), der Eintrag selbst steht ohne #.
# Above each entry is its description (# ...), the entry itself has no #.

# Ueber die Rampe: bei gemischten Ladungen nur Tiefbett, nie Schwanenhals
# over the ramp: in mixed loads low-bed only, never gooseneck
ramp: true

# Zurrart: direct | top_over (ersetzt die des cargo_model_match)
# lashing method: direct | top_over (replaces the one of the cargo_model_match)
lashing_method: direct

# Gurt durch die Ladung beim Sichern von Hand: true | false
# strap through the cargo when securing by hand: true | false
lash_through: false

# Volumen je Einheit in m3 (ersetzt das der Fracht-Definition)
# volume per unit in m3 (replaces the one of the cargo definition)
volume: 15.6

# Einheiten je Ladungsmodell = 1 / Faktor (hier 1 Einheit je Modell)
# units per cargo model = 1 / factor (here 1 unit per model)
unit_volume_factor: 1
