    Cargo securing¶

    Small optional files tell the mod how a cargo is secured and how it behaves: edge guards, wear at edges, tipping and sliding, anti-slip mats, deck and your own lashing gear. They work for every cargo mod: the files sit next to the files the game already loads. The examples in the def/ folder of this package show the format. Everything works with the option "secure cargo yourself"; anti-slip mats are laid by the mod itself without the option.

    1. Cargo model (cargo_model_match)¶

    Same folder and same name as the cargo_model_match file of the cargo, only with .v3def:

    /def/vehicle/cargo/your_cargo/model_area.sii
-> /def/vehicle/cargo/your_cargo/model_area.v3def

    If there are several match files (e.g. model_area.sii and model_area_1.sii), each one gets its own .v3def. All entries are optional; without the file the defaults apply. An entry with a wrong format is listed as an error in the log (file and value read), that line is then not used.

    1a. Edge guards¶

    edge_guard: trueguards can be placed when securing by hand (default: false)
    edge_guard_width: 0.20width of the guard in m, 0.01 - 2 (default: strap = strap width + 0.20, threaded + 0.04; chain 0.20)
    edge_guard_leg: 0.10leg length on each side of the edge in m, 0.005 - 1 (default: strap 0.10, threaded 0.05; chain 0.15)

    1b. Wear at edges¶

    edge_wear: 0.4wear of the strap at an edge without guard, 0.0 - 1.0 (default 0.5). With a guard only a fifth counts. Together with the give of the ratchet the strap becomes loose (from 75 %).
    edge_crush: 0.5crushing of the cargo at an edge without guard, 0.0 - 1.0 (default 0.5) - for a later version, no effect yet.

    1c. Tipping of loose cargo¶

    If a lashing on a cargo piece is loose, the piece can tip in corners and when braking - as far as the loose lashing lets it - and drops back with an impact. A tight lashing on the piece holds it. All values in model coordinates (m): x across, y up, z along.

    tilt[]: falsethis cargo model never tips (e.g. very flat or firmly chocked cargo). Default: true.
    tilt_base[]: "single|(x, z)|radius"
    One support point (wheel, foot, prop). Radius = half tyre or foot
    width, the contact reaches that far outwards (optional, default 0).
tilt_base[]: "area|(x, z)|(x, z)"
    A support area: outer dimensions as two opposite corners
    (crate, pallet, frame, chocks).
tilt_base[]: "ring|(x, z)|outer radius|inner radius|angle from|angle to"
    A ring or ring segment (upright pipe section, formwork, arch):
    circle centre, outer and inner radius, arc from - to in degrees
    (0 = towards +x, 90 = towards +z). Without angles: full ring.
    Example half ring over -x: "ring|(1.53, 0.0)|3.05|2.40|90|270"

    Several lines and all types can be mixed; the support area is the outline around all points. The piece tips about its edge. Without tilt_base[] the mod uses the lowest points of the model (mesh).

    Material or friction value (optional, first field of each tilt_base line):
what the support area is made of. This gives the static friction on the
deck (for sliding) and whether an anti-slip mat is needed there
(section 3). Default 0.45.
    "material|single|(x, z)|radius"
    "material|area|(x, z)|(x, z)"
    "material|ring|(x, z)|outer radius|inner radius|angle from|angle to"
Materials (value on a wooden deck):
    wood 0.50       sawn wood (beams, crates, skids)
    plastic 0.20    plastic
    metal 0.45      steel / metal
    concrete 0.55   concrete
    rubber 0.60     rubber (tyres, rubber tracks)
    straw 0.40      straw
Instead of a material a number 0.01 - 1.5 works too (friction on a wooden
deck). Guide values per EN 12195-1: planed wood 0.3, rough concrete 0.7.
The value is combined with the deck of the trailer (section 4).
Example wheel: tilt_base[]: "rubber|single|(-0.75, -0.40)|0.08"
Example skid: tilt_base[]: "wood|area|(-1.15, -0.70)|(1.15, -0.60)"

    coll_base[]: "single|(x, y, z)|radius"
coll_base[]: "area|(x, y, z)|(x, y, z)"
coll_base[]: "cylinder|(x, y, z)|(x, y, z)|radius"
    parts that touch the deck when tipping (forks, bucket, attachment,
    overhang). Tipping stops there. single = point with radius,
    area = surface from two opposite corners (x, y, z). Height and width
    change evenly along the length (z): different heights = sloped. If the
    corners are left and right of the centre, the surface is a trapezoid
    symmetric to the centre (+-x at each end, e.g. wide and low at the
    fender, narrow and higher at the end of the box). If both are on the
    same side, it is a rectangle between them (e.g. mast beside the centre).
    cylinder = cylinder (boiler, pipe): centre of both end faces (start and
    end point) and radius. A second radius after it applies at the end point
    (cone, transition): "cylinder|(x, y, z)|(x, y, z)|1.70|0.80"
    Without entry the mod uses all model points up to 0.6 m height.
    tilt_cog[]: (x, y, z)centre of gravity. Without entry: centre of the model. Low and far inside = stable, high and close to an edge = tips early.
    sounds[]: "drop|/sound/your_mod/your.bank#your_event"
    sound when dropping back (FMOD event, one-shot, parameters impact 0-1 =
    hardness of the impact, mass 0-1 = weight / 20 t, aero_wnd 0-2 = cabin
    closed/open). "drop|-" = no sound. Without entry:
    /sound/lphd/lashing.bank#cargo_drop. .soundref is possible too.

    Several models in one match (several data_path[]):
Without a number, tilt[], tilt_base[], coll_base[], tilt_cog[] and sounds[] apply to
models of the match. With a number only to the model at that position in
data_path[] (first = 0):
  tilt_base[0]: "area|(-1.08, -1.50)|(1.08, 5.80)"
  tilt_cog[0]: (0.00, 1.35, 1.80)
  sounds[0]: "drop|/sound/lphd/lashing.bank#cargo_drop"
  tilt[1]: false
tilt[], tilt_cog[] and sounds[] with a number replace the value without.
tilt_base and coll_base with a number are added: all lines without a
number and all with the model's number apply together.

    2. Lashing gear¶

    Own file in the folder /def/vehicle, name starts with lashing_gear_data:

    /def/vehicle/lashing_gear_data.your_mod.v3def

    In square brackets the name of the cargo_lashing_gear unit from the lashing_gear_data file of the game or the mod (e.g. .strap, .chain).

    loosen_minutes[.your_strap]: 10
    minutes of hard driving (summed, e.g. corners with about 4 m/s2
    lateral) until the lashing loosens. Without entry: strap 10, chain 20.
    Added per lashing: a spread, the position on the cargo piece, the
    weight per lashing, the free length and the angle.

    lashing_capacity[.your_strap]: 2.5
    lashing capacity LC in t (label in daN / 1000, e.g. LC 2500 daN
    = 2.5). The more the lashing is loaded (weight per lashing / LC),
    the faster it loosens. Without entry: strap 2.5, chain 6.3.

    sounds[.your_strap]: "loose|/sound/your_mod/your.bank#your_event"
    sound of the loose lashing (middle of the strap), loop with the
    parameters aero_speed 0-200, aero_wnd 0-2, slack 0-1.
sounds[.your_strap]: "rattle|/sound/your_mod/your.bank#your_event"
    rattling ratchet or tensioner, same parameters.

    "-" instead of a path = no sound. Several equal names: the straps take turns. Without entry: strap strap_noise + ratchet_rattle, chain chain_noise (no separate rattle), all from /sound/lphd/lashing.bank.

    3. Anti-slip mats¶

    For each support area from tilt_base[] the mod calculates: value of the material x factor of the deck at that spot (section 4). Below 0.60 the area gets an anti-slip mat. Without tilt_base[] there are no mats.

    • With "secure cargo yourself" the player lays the mats before loading in a separate scene (marker at each area). Without the option, on pre-loaded job trailers and on parked trailers the mod lays them itself.
    • Mat: 8 mm thick, friction 0.60 regardless of cargo and deck. The cargo stands with its underside on the mat; if only some areas have mats, it rests tilted on the mat edge.
    • Size: small area (both sides up to 0.5 m) completely; larger area pieces of 0.3 m at the corners and every 1.2 m along the edges; single as a square (radius up to 0.25 m) or pieces on the circle; ring pieces on the middle radius every 1.2 m.
    • Mats are cut off at the edge of the deck. Pieces under 2 cm are left out - single needs a radius of at least 0.01 for that.

    Tip: tyres and rubber tracks (rubber) need no mat, wooden skids and steel on wood do, on a metal deck almost everything does.

    4. Deck (trailer)¶

    Own file next to the body file of the trailer, same name with .v3def (without a body next to the chassis file):

    /def/vehicle/trailer_owned/your_trailer/body/your_body.sii
-> /def/vehicle/trailer_owned/your_trailer/body/your_body.v3def

    floor: wood               deck: wood (factor 1.00), metal (0.70) or film
                          (film-faced plywood, 0.60). Default: wood.
floor[]: "metal|x1|x2"    strip with a different deck over the full length,
                          from x1 to x2 across in m (trailer coordinates,
                          0 = centre). Several lines possible, e.g. steel
                          frame outside and wood in between.

    The factor is multiplied with the value of the material of the support area (sliding and anti-slip mats).

    5. Models of the lashing gear (hook, ratchet, tensioner)¶

    So that hook and ratchet sit correctly when securing, the model gets a file next to its .pmd, same name with .v3def. These are the models named in the lashing_gear_data (hook at the start, hook at the end, ratchet or tensioner):

    /vehicle/your_mod/lashing/your_hook.pmd
-> /vehicle/your_mod/lashing/your_hook.v3def

    Hook:

    lphd_lash_model : .hook {
    pivot: (0.0, 0.0, -0.025)     pivot: the point with which the hook hangs
                                  in the eye or at the lashing point
    tip: (0.0, -0.04, -0.03)      tip (read, currently without effect)
    sounds[]: "hook|/sound/your_mod/your.bank#hook"
}

    Ratchet / tensioner:

    lphd_lash_model : .binder {
    in: (0.0, 0.0, 0.085)         shaft the strap or chain runs onto
    fixed: (0.0, 0.0, 0.0)        bolt the ratchet hangs on
    contact: (0.0, -0.018, 0.042) contact: this side rests against the
                                  vehicle or the cargo (without entry:
                                  the same all round, e.g. chain tensioner)
    lever: (0.0, 0.045, -0.092)   end of the lever (tensioning)
    sounds[]: "ratchet_up|/sound/your_mod/your.bank#ratchet_up"
}
    • points in metres in the space of the model, written as (x, y, z)
    • without a file or without points the model lies as the game sets it
    • a ratchet needs in and fixed, otherwise it counts as without points

    Sounds (sounds[]: "name|path", path to a .soundref or bank#event, "-" = no sound, several equal names: one of them at random). Without entry it is silent.

    hookhook_in hooking in (otherwise hook) hook_out unhooking (otherwise hook) strap_throw / chain_throw throwing the strap or chain over, at the end hook (otherwise throw)
    ratchetratchet_up lever up ratchet_down lever down, tensioning (otherwise tension) ratchet_open opening (otherwise ratchet_up)

    All examples for download: resources_lashing_data.zip

    # Fleet & Road Realism - Beispiel: Ladungssicherung fuer your_cargo (neben model_area.sii)
# Fleet & Road Realism - example: cargo securing for your_cargo (next to model_area.sii)

# Alle Eintraege optional / all entries optional - siehe / see README_lashing_data.txt

# ---- Kantenschoner / edge guards ----

# Schoner beim Sichern von Hand setzbar (true/false)
# Guards can be placed when securing by hand (true/false)
edge_guard: true

# Breite des Schoners in m (0.01 - 2)
# Width of the guard in m (0.01 - 2)
edge_guard_width: 0.20

# Schenkellaenge je Seite der Kante in m (0.005 - 1)
# Leg length on each side of the edge in m (0.005 - 1)
edge_guard_leg: 0.10

# Scheuern des Gurts ohne Schoner 0.0 - 1.0
# Strap wear without guard 0.0 - 1.0
edge_wear: 0.4

# Quetschen der Ladung ohne Schoner 0.0 - 1.0 (spaetere Version)
# Cargo crushing without guard 0.0 - 1.0 (later version)
edge_crush: 0.5

# ---- Kippen, Rutschen und Antirutschmatten / tipping, sliding and anti-slip mats ----
# Modellkoordinaten in m: x quer, y hoch, z laengs
# Model coordinates in m: x across, y up, z along

# Kippen fuer dieses Modell ausschalten (true/false, Standard true)
# Switch tipping off for this model (true/false, default true)
# tilt[]: false

# Aufstandspunkte: "Material|single|(x, z)|Radius" - hier 2 Gummiraeder und ein Stuetzfuss aus Kunststoff
# Support points: "material|single|(x, z)|radius" - here 2 rubber wheels and a plastic support foot
# Material: wood, plastic, metal, concrete, rubber, straw (oder Reibwert 0.01 - 1.5 / or friction 0.01 - 1.5)
# Liegt Material x Ladeboden unter 0.60, bekommt die Flaeche eine Antirutschmatte
# If material x deck is below 0.60, the area gets an anti-slip mat

tilt_base[]: "rubber|single|(0.75, -0.40)|0.08"
tilt_base[]: "plastic|single|(0.00, 1.00)|0.05"

# Oder Standflaechen: Aussenmasse als zwei Ecken (x, z) - hier zwei Holzkufen
# Or support areas: outer dimensions as two corners (x, z) - here two wooden skids
# tilt_base[]: "wood|area|(-1.15, -0.70)|(1.15, -0.60)"
# tilt_base[]: "wood|area|(-1.15, 0.60)|(1.15, 0.70)"

# Teile, die beim Kippen auf der Ladeflaeche aufsetzen (Gabel, Schaufel) - Kippbegrenzung
# Parts that touch the deck when tipping (forks, bucket) - tipping limit
coll_base[]: "area|(-0.40, 0.05, 1.20)|(0.40, 0.15, 1.60)"

# Schwerpunkt (x, y, z)
# Centre of gravity (x, y, z)
tilt_cog[]: (0.00, 0.80, -0.30)

# Ton beim Rueckfall auf die Ladeflaeche ("drop|-" = kein Ton)
# Sound when dropping back onto the deck ("drop|-" = no sound)
sounds[]: "drop|/sound/your_mod/your.bank#cargo_drop"
